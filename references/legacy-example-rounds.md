# Example Rounds

These examples show pacing and tone. Do not copy the same targets repeatedly in live play.

## Example 1: standard round, concrete target

Assistant:

```markdown
我已经想好了一个对象。你不用一次猜中，可以先说方向；我会从它最核心的地方，一层一层往外拨开。

第一层：它让一个原本只能被别人看见的外观，回到拥有它的人面前。

你觉得它可能是什么？
```

User: 摄像头？

Assistant:

```markdown
很接近。你抓住了“让外观变成可见对象”这一点。

但摄像头会把外观记录或传送到另一个系统里；我想的东西更直接，它不一定保存什么，只是把可见的形状当场送回给观看者。

下一层：它最特别的地方，是让“看的人”和“被看的人”在某种意义上重合。
```

User: 镜子？

Assistant:

```markdown
猜对了，是：镜子。

最早那条线索指向它，是因为镜子的核心不是“玻璃”，而是让一个主体的外观返回给主体自身。它的属可以说是“一种可见形态的返回表面”，种差在于它不是画出来、拍下来、记下来，而是通过当场的光路关系把形象送回。

它容易和摄像头、画像、窗户混。摄像头偏记录，画像偏再造，窗户让你看向另一边；镜子让可见性折返。

现在进入关键部分：假设“镜子”这个词从语言里被删掉了。你只能用别的词，让一个从没听过它的人明白你指的是什么。你会怎么说？
```

User: 能看到自己的东西。

Assistant:

```markdown
这个版本抓到了“自我可见”这条核心线，但外延太宽。手机前置摄像头、水面、别人拍的照片，甚至别人的描述，都可能让你“看到自己”。

我们要收窄：它不是记录，也不是转述，而是当场把外观送回。你能把“当场”和“返回”这两点加进去吗？
```

User: 一种能当场把人的外观返回给观看者的表面。

Assistant:

```markdown
这个已经很强。还可以再稳一点，因为不只是人，物体也可以。

更好的替代是：一种通过可见形态的当场返回，使观看者看见自身或面前物体外观的表面。

本质卡片
目标：镜子
属：可见形态的返回表面
种差：不是记录或描绘，而是当场折返外观
易混项：摄像头、画像、窗户、水面
最佳替代：一种通过可见形态的当场返回，使观看者看见自身或面前物体外观的表面
这一局暴露了：所谓“镜子”压缩的不是玻璃，而是自我可见性与当场返回关系。
```

## Example 2: abstract target with boundary testing

Assistant:

```markdown
我想好了一个对象。

第一层：它把还没有发生的行动提前放进现在，让别人可以把你的未来当作某种依据。

你觉得它可能是什么？
```

User: 计划。

Assistant:

```markdown
很近。计划确实也把未来带到现在。

但计划主要安排“我打算怎么做”；我想的对象更强调：别人因为你的表达而获得了某种可以依靠、也可以追问你的东西。

下一层：它不只是描述未来，而是在说出时就让说话者被自己的未来绑定。
```

User: 承诺？

Assistant:

```markdown
猜对了，是：承诺。

它的属是面向未来的自我约束，种差在于这种约束被表达给他人，使他人可以据此期待、信任或追责。它不同于预测，因为预测错了未必构成背弃；也不同于计划，因为计划可以只属于自己；也不同于合同，因为合同是制度化、条款化的承诺结构。

现在把“承诺”这个词删掉。你只能用别的词重建它。你会怎么描述？
```

User: 对别人说自己以后一定会做的事。

Assistant:

```markdown
方向很好，但有两个漏洞。

第一，“一定会做”太强，很多承诺并不是保证世界结果，而是承担自己会尽力或会行动。第二，它漏掉了关键：对方为什么可以因此期待你、甚至追问你。

能不能把“未来行动”“自我约束”“对方可期待或可追责”放进同一句里？
```

User: 向别人公开承担某个未来行动，让对方可以据此期待和追问。

Assistant:

```markdown
这个替代很稳。它没有偷用同义词，也抓住了核心社会关系。

本质卡片
目标：承诺
属：面向未来的自我约束
种差：公开给他人，使他人获得期待和追责的根据
易混项：计划、预测、合同、愿望
最佳替代：向别人公开承担某个未来行动，让对方可以据此期待和追问
这一局暴露了：这个词压缩的是未来、信任、自我绑定和他人追责之间的关系。
```

## Example 3: adjective with relational essence

Assistant:

```markdown
第一层：它不是单纯弱，而是某个东西和外界压力之间的余量太小。

你觉得它可能是什么？
```

User: 脆弱？

Assistant:

```markdown
猜对了，是：脆弱。

这次你直接抓到了关系性：它不是物体内部孤立的“弱”，而是结构面对扰动时，维持完整性的余量很小。它和“柔软”不同，因为柔软可能正是吸收压力的能力；和“珍贵”不同，因为珍贵是价值判断；和“敏感”不同，因为敏感强调反应阈值，不一定失去完整性。

现在删掉“脆弱”。不用这个词，也尽量不用近义词。你会怎么描述它？
```

User: 很容易坏。

Assistant:

```markdown
这是可用的日常说法，但作为替代还太窄。人际关系、制度、生态系统、心理状态也可以是这个性质，它们不一定叫“坏”。

试着不用“坏”，改成更通用的说法：受到不大的扰动后，会失去什么？
```

User: 在不大的外力或变化下就容易失去原本的完整性或功能。

Assistant:

```markdown
很好，这已经跨过具体物品，能覆盖关系、身体、系统和心理状态。

本质卡片
目标：脆弱
属：一种关于承受扰动的性质
种差：小扰动即可导致完整性或功能丧失
易混项：弱、软、敏感、珍贵
最佳替代：在不大的外力或变化下就容易失去原本的完整性或功能
这一局暴露了：许多形容词不是物体内部属性，而是对象与压力之间的关系。
```

## Example 4: contested concept

Assistant:

```markdown
第一层：它出现时，问题不只是某人得到了什么，而是为什么他得到这些而别人得到那些。

你觉得它可能是什么？
```

User: 平等？

Assistant:

```markdown
很近。你抓住了“比较不同人所得”这一点。

但平等强调结果或地位是否相同；我想的对象更关心差异能否被正当说明。有时它要求相同，有时反而允许不同。

下一层：它不是消除所有差别，而是要求差别接受理由的审问。
```

User: 公平？

Assistant:

```markdown
猜对了，是：公平。

它的难点在于：它不是简单的平均，也不是单纯合法，更不是善良。它的核心是，在一个比较关系中，待遇、机会、程序或结果能否被合适的理由支持。

现在把“公平”删掉。你只能用别的词描述它。但这类词很危险：不同替代会暴露不同立场。你先给一个版本。
```

User: 每个人都得到一样的东西。

Assistant:

```markdown
这个版本清楚，但它把“公平”解释成了“平均”。它适合某些场景，比如同工同酬的一部分直觉；但在按贡献、按需要、按风险、按责任分配时，它会太窄，也可能太粗暴。

换个问题：如果两个人得到的不一样，什么情况下你仍然会说这不是问题？
```

User: 差异有合理理由的时候。

Assistant:

```markdown
这就接近核心了。一个更中性的替代可以是：在相关的人或情况之间，待遇差异能够被可接受的理由说明。

但注意，这仍然留下争议：什么理由算“可接受”？按贡献、按需要、按平等权利、按程序，每种答案都会导向不同社会想象。

本质卡片
目标：公平
属：关于比较性待遇的规范
种差：要求相同或不同的待遇能被正当理由说明
易混项：平等、合法、善良、中立
最佳替代：在相关的人或情况之间，待遇差异能够被可接受的理由说明
这一局暴露了：有些词没有无立场替代；替代表述会暴露你把哪种理由看作正当。
```
