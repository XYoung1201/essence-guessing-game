# 一代示范局存档(legacy-example-rounds)

这里存的是**一代两幕结构**(猜词 + 去标签重述)的四个旧示范局,外加一局"手"的命名片段。留它们只为两样东西:**放线收线的节奏**,与**挑毛病的口吻**——这两样至今没变。结构已经变了:真实对局一律走现行四幕,本册任何地方与 game-protocol.md 冲突,以后者为准。

**别照搬的四处**(旧 → 现行):

| 旧做法 | 现行做法 |
|---|---|
| 去标签重述:删词后向**主持人**重述 | 幕二:造失语世界,向**居民**解释;盘问循环 + 封印一问(protocol 2) |
| 卡片里的"最佳替代"栏 | 拆成两件:幕二收束的**精确解释** + 幕三玩家自铸的**新名**(新卡式见 protocol 4.6) |
| 主持人并列 2–3 个候选名供玩家挑 | **禁代铸**:玩家铸名,主持人只审(3.3);"无唯一最佳"仍成立,但候选都得是玩家的(3.4) |
| 对照完邻居即收局 | 幕四回望:一问一答、实战检验、含窍 / 坑两栏的卡片、迁移一题(protocol 4) |

## 旧局一 · 钟表(具体名词,直白偏严谨风格)

**本局答案:钟表。**

**线索梯**
1. (本体)一个把看不见、摸不着、只能感受的东西,转译成你能一眼读出的位置或数字的装置。
   —— 故意多义:钟表、温度计、体重秤、仪表盘都说得通。
2. (种差)它量的不是冷热、不是轻重,而是"流逝"本身——一种只增不减、对谁都一样、退不回去的量。
   —— 收窄到"计量时间":日晷、沙漏、钟表。
3. (结构)它内部通常有一个稳定重复的节律源(摆动、振荡、滴漏),靠数这个节律来计量。
   —— 把日晷排除(日晷靠影子,不靠内部节律)。
4. (情境)它在黑夜里、室内、能连续不断地工作,并把结果显示成一圈刻度上的指针,或跳动的数字。
   —— 指向钟表。

**代表性走向**
玩家在第 2 条猜"温度计?",你回应:"方向对了一半——它确实是'把感受变成读数',但它量的那个东西有个温度没有的脾气:只增不减、退不回去。"玩家第 3 条后猜"钟 / 表",命中。

**去标签重述(苏格拉底片段)**
- 你:把"钟表"删掉。只用别的词,让我重新明白你指什么。
- 玩家:一个能告诉你时间的东西。
- 你:"告诉你时间"里就藏着被删掉的那个词的影子——你等于说"一个能报时的东西",而"时"正是要拆开的。换个不靠"时间 / 计时"这类词的说法试试。
- 玩家:一个不停数着自己稳定心跳、再把数到的数翻译成一圈刻度上指针位置的装置。
- 你:好多了,几乎不循环了。但它会套到节拍器上——节拍器也有稳定心跳、也外显。差在哪?
- 玩家:节拍器只是打拍子,不累计;它要把"从某个约定的起点到现在一共流过多少"累加起来并显示。
- 你:这下外延对齐了。收敛。

**本质卡片(旧式)**
```
属:    一种测量装置
种差:  测的是单调累加、不可逆的流逝量,靠内部稳定节律计数并外显
易混项:节拍器(有节律但不累计)、温度计(可逆、非累加)
最佳替代:一个靠数自己稳定节律、把"自某约定起点起累计流过的总量"显示在刻度上的装置
这一局暴露了:"报时""计时"这种词是循环陷阱——一拆才发现钟表的本质是"给一条不可逆的累加量做外显计数器"
```

〔今注〕节拍器那一下,正是现行**邻居代入测试**(definition-tools.md 第三节)的手感来源;"报时是循环"的审法,居民版措辞见七病速诊表『循环』。现行对局里,这段重述应整段换成幕二的失语世界。

## 旧局二 · 突然(副词,诗意偏严谨风格)

**本局答案:突然。**

**线索梯**
1. (本体)我不是一个东西,也不描述一个东西长什么样;我修饰"变化"——我说的是变化和时间的关系。
   —— 信号:这是个修饰变化的副词。多义:迅速、瞬间、渐渐、忽然……
2. (种差一)我说:这个变化占的时间极短,短到夹在"之前"和"之后"中间几乎没有过渡。
   —— 收窄到"快 / 瞬间"一族。
3. (种差二)但我不只是"快"。我还说:没人料到、没有铺垫、没有征兆。一场被预报了三天的台风,哪怕来得猛,也不是我。
   —— 把"迅速 / 飞快"排除(它们不含"出乎意料")。

**代表性走向**
玩家第 2 条猜"迅速 / 快",你回应:"快是其中一半。但'快'可以是被预告的、被期待的;我还要那一下子的'没想到'。"玩家猜"突然 / 忽然",命中。

**去标签重述(苏格拉底片段)**
- 你:删掉"突然"。
- 玩家:很快地、一下子地。
- 你:漏了它最要命的一束含义。被预报的台风也"一下子"登陆,你会用它修饰吗?
- 玩家:在没有任何预兆、来不及反应的极短时间里。
- 你:这下两束都在了——"极短"加"无预兆"。再做个对照:它和"骤然""冷不防"这几个邻居,各偏重哪一束?
- 玩家:骤然像是又快又猛,程度更重;冷不防偏重那个"被打个措手不及"的承受者视角。
- 你:对。所以没有唯一最佳——看你想保住哪一束。要中性的"无预兆 + 极短",你那句就是最佳;要强调承受者措手不及,就往"冷不防"那束靠。

**本质卡片(旧式)**
```
属:    修饰"变化"的副词
种差:  极短时间 + 无预兆,二者缺一不可
易混项:迅速(只有快,可被预期)、骤然(偏重程度)、冷不防(偏重承受者措手不及)
最佳替代:在没有任何预兆、来不及反应的极短时间里(发生)
这一局暴露了:一个词常是几束语义线的捆绑;转述逼你逐束点名,也逼你承认"最佳"取决于你要保哪一束
```

〔今注〕"骤然 / 冷不防各偏哪束"的对照,旧版由主持人摆出;现行让玩家**先押**每个邻居的种差、再核对——这正是近邻分茎(quick-games.md 第 3 局)的雏形。

## 旧局三 · 苦(感受性形容词,逼出"指物定义"的边界)

**本局答案:苦。**

**线索梯**
1. (本体)我是一种你没法用纯语言、传给一个从没经历过我的人的东西。我住在某一个感官的内部。
   —— 信号:这是个感受性质(感受质)。多义:酸、甜、咸、香、痛、痒……
2. (种差一)具体说,我属于"尝"这个感官,我是它能分辨的几个基本类别之一。
   —— 收窄到味觉:酸、甜、苦、咸、鲜。
3. (种差二)在这几个里,我是身体最初用来警告"别吃、可能有毒"的那一种;可人后来偏偏学会在咖啡、茶、啤酒里追求我。
   —— 指向苦。

**代表性走向**
玩家第 2 条后在"酸 / 苦"间犹豫,你回应:"酸也警告,但它更多提示'坏了 / 没熟';我提示的是'有毒、危险',而且我天然最让人想躲。"玩家猜"苦",命中。

**去标签重述(关键:这里语言会失灵)**
- 你:删掉"苦"。只用别的词,让我重新明白它是什么。
- 玩家:一种不好的味道。
- 你:太宽——酸、馊、咸过头都能算"不好的味道"。再准些?
- 玩家:一种让人皱眉、想吐掉、舌根发紧的味道。
- 你:好了很多,但你发现没有——你已经只能靠"它让你做什么反应"来描它,没法直接说"它本身是什么"。再逼一步:把这句话念给一个天生尝不出味的人,他能复原出这个味道吗?
- 玩家:复原不出。
- 你:这正是这局的题眼。到了纯粹的感受,语言只能绕着它指(它让你皱眉)、或者直接"指物":黄连的那个味、咖啡因的那个味。**定义在这里碰到了天花板**——有些东西,只能被经历、被指认,不能被说尽。
- 你:所以最佳替代不是一句定义,而是一组指认 + 一句反应描述:"黄连、苦瓜、纯咖啡因那一类的味道;入口让人本能想吐掉。"

**本质卡片(旧式)**
```
属:    味觉的一种基本感受质
种差:  本能上提示"有毒 / 危险"、最催人回避的那一类味道
易混项:酸(提示腐坏 / 未熟)、咸过量(刺激但非毒性警告)
最佳替代:只能"指"——黄连、咖啡因那一类的味道 + "入口本能想吐掉"
这一局暴露了:指物定义的存在与定义的边界——纯感受无法被语言说尽,只能被经历和指认
```

〔今注〕题眼至今未动,走法已换:现行版把同一目标递给**缺感者**,让玩家亲自撞上语言的天花板,而不是听主持人宣布它——见 target-bank.md 示范局 C;触岸的判准与收法,见 definition-tools.md 第八节。

## 旧局四 · 自由(本质争议概念,逼出"无中立转述")

**本局答案:自由。**

**线索梯**
1. (本体)我不是一个东西,而是一种"关系状态"——关于"想做的"和"能做的"之间,有没有阻碍。
   —— 多义:自由、权利、能力、机会……
2. (种差一)我有两张脸,人们为我是哪张脸吵了几百年:一张说"没人拦着你就够了"(消极),另一张说"你得真有能力、有条件去做才算数"(积极)。
   —— 收窄,且已埋下"争议"的引线。

**代表性走向**
玩家第 2 条猜"自由",命中——这局的重头不在猜,在重述。

**去标签重述(关键:转述会暴露立场)**
- 你:删掉"自由"。只用别的词,让我明白你指什么。
- 玩家:没有人强迫你、限制你的状态。
- 你:注意,你刚刚替我做了一个选择——你只拿了"消极"那张脸。一个人没人拦着、却穷到哪也去不了、什么也做不成,按你这句他"自由",你认这个结论吗?
- 玩家:……那加上"并且有实际能力去做你想做的事"。
- 你:那你又倒向了"积极"那张脸。可这下另一个麻烦来了:照这句,凡是能力不足都算"不自由",于是几乎没人完全自由——这个结论你认吗?
- 玩家:看来怎么转述,都会偏向某一种主张。
- 你:这就是题眼。**对"自由 / 公平 / 艺术"这类本质争议概念,不存在中立的转述**——你选哪束语义线,等于你站了哪个立场。所以这一局的"最佳替代"不是一句定义,而是把分歧摆明:
  - 偏消极:没有外力强制或阻拦你去做选择的状态;
  - 偏积极:你不仅没被拦,还实际具备做成所选之事的能力与条件。
- 你:用哪句,取决于你要论证什么——而这正是为什么"谁掌握定义,谁就掌握结论"。

**本质卡片(旧式)**
```
属:    一种关于行动与阻碍的关系状态
种差:  "想做"与"能做"之间障碍的有无;且本身分裂为消极 / 积极两种主张
易混项:权利(他人应许可)、能力(你自身可为)——自由常被偷换成其中之一
最佳替代:无单一中立版本;须二选一并标明立场(消极:无外力阻拦 / 积极:有能力做成所选)
这一局暴露了:定义可以裹挟立场——对争议概念,下定义即是表态,看穿这点才不被定义牵着走
```

〔今注〕消极 / 积极两版,旧版由主持人摆出;现行应由玩家**自写双版并互相验尸**——即立场炼金(quick-games.md 第 5 局)。主持人在这类概念上的三戒(不裁对错、只显走私、用即标明),见 definition-tools.md 第七节。

## 附 · 手(反转局的命名片段)

这局发生在一次反转模式里(玩家出题"手"、主持人猜中;按旧版 5.1 的默认,命名幕交还玩家做),**没有留下逐字记录**。以下按现行 protocol 3.2 / 3.3 引用它的句子重建,只取命名链:

- 玩家(铸):「**执探**」——把"执持"与"探察"两条职能线焊在一起。
- 主持人(审):"这像个动作,不像个东西——它到底是个'什么'?落脚点呢?"〔只有种差、没有落脚点〕
- 玩家:「**前肢执探**」。
- 主持人(审):"你把'前肢'这种**位置**铸进去了——位置是偶性:倒立的人,手还是手。而且想靠位置把脚排出去也排不动,分家是职能的活。落脚点要的是贴它真身的归类。"〔偶性入名〕
- 玩家(定稿):「**肢端执探**」。
- 主持人:"成。有人拿'脚也长在肢端'钻空子吗?钻不动——**属罩住邻居不是病**,'肢端'管归类;'执探'那条职能线,已经把脚分了出去。**属管归类,种差管分家。**"

**本质卡片(旧式,重建)**
```
属:    肢端(肢体末端的一段)
种差:  以执持与探察为职能
易混项:脚(同为肢端,职能在承重与行走)
最佳替代:肢体末端那段以抓握、操持、触探为职能的部分
这一局暴露了:位置是偶性,职能才承重;落脚点管归类,种差管分家
```

〔今注〕这一局是现行命名幕的胚胎:三版名字**全部出自玩家**,主持人只审——"玩家铸、主持人不代铸"在此已经成形;那几句审名的话("这像个动作,不像个东西""位置是偶性,换职能线")原样进入了 protocol 3.2 与 3.3;"属管归类,种差管分家"的分工铁律,现归档于 definition-tools.md 第二节。
