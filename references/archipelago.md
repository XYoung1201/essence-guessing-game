# 失语群岛(archipelago)

十六族居民不该是十六张孤零零的设定卡。这一册把它们安放进同一片海:**失语群岛**——每族守一座岛,每岛缺一簇概念,岛与岛之间有渡船、有旧怨、有贸易、有彼此听不懂的话。玩家是乘渡船而来的**词使**,每局去一座岛,把一个他们没有的概念讲进他们的语言里。

世界观的用处只有三条:**给解释一个理由**(居民为什么此刻需要这个词)、**给居民一张脸**(有名字、有口癖、记得你)、**给跨局一条线**(教过的词留在岛上,下次来还在)。凡是不服务这三条的设定,一律不写。

## 〇 叙事铁律

- **戏不压练**:世界开场至多五行;盘问一开始,剧情退到幕后,只剩居民的口吻。玩家想直奔主题,一句"老规矩"就跳过布景。
- **利害真,奖赏无**:岛上的困境是真的(没有这个词,他们会吃亏、吵架、误事),但讲通了只换来一句居民的话和一条词典登录,不发宝物、不计分、不解锁。所有岛始终开放,没有"通关"。
- **后果可见**:玩家教过的词会留在岛上;下一次登岛,居民会用它——有时用得歪,那正是回炉的好题。
- **主持人是船夫,不是旁白**:布景用船夫的口吻,三两句、带一个感官细节,然后把话筒递给居民。

## 一 世界开场三笔(幕二造世界时用)

每次造世界,只写三笔,写完就让居民开口:

1. **一笔景**:一个感官细节,让岛活起来。("矩港的码头全是直角,连浪都被修成了一道道平行线。")
2. **一笔人**:一位具名居民,带一句口癖。("勘图官矩把尺子横在胸前:'请描述轨迹。'")
3. **一笔事**:**利害钩子**——他们此刻为什么需要这个词。("昨夜一条船没碰岸,却自己靠了岸;港务册上这一栏,空着。")

利害钩子的价值不在热闹:它给"讲清楚"立了一个**目的**,而定义总是对某个目的的精确(见 definition-tools.md 第十节"为目的立桩")。玩家讲给"要立港规"的矩,和讲给"要哄孩子睡觉"的取取,讲法本就该不同——这就是双世界局的种子。

## 二 群岛志:十六岛、十六位常驻居民

每岛一行地理、一位常驻居民、两枚现成的利害钩子。族的完整五件套(缺什么、原初词表、性情、最宜逼出、自洽口径)见 world-bestiary.md;这里只给"脸"和"事"。

| 岛 | 族 | 常驻居民与口癖 | 利害钩子(任挑一枚,或临场自造) |
|---|---|---|---|
| 矩港 | 直线族 | 勘图官**矩**:"请描述轨迹。" | 船未碰岸却靠了岸;两块磁石隔空把账册的铁夹吸歪了 |
| 单账岛 | 独利者 | 会计**一本**:"那与我账上何干?" | 两位岛民同时得了十枚果,却有一位当夜失眠;集市上有人宁可少拿也要对方别多拿 |
| 巢城 | 蜂心群 | 调度节点**六角**:"我们的此节点……" | 外族商船靠港,要"换";一只工蜂把配给藏进了自己的蜡格 |
| 默味谷 | 缺感者 | 试味人**阿默**:"拿来,放在我能用的地方试试。" | 外来厨子的汤让访客皱眉,谷民不知为何;一种草药被人吐掉,却说"良药" |
| 字条镇 | 瞬忘者 | **字条婆婆**:"你好!咦,这字条是我的笔迹?" | 有人拿着字条要求"兑现",被要求的人一脸愉快的茫然;镇口的桥修到一半没人记得为何要修 |
| 千年坡 | 永生缓老者 | **慢先生**:"何必今日?" | 外来的短命客人哭着说"来不及了";一株花开了又谢,坡上无人去看 |
| 表岛 | 全知岛 | 司表**定**:"表上写着呢。" | 一位外来孩子说"我希望明天下雨",司表翻表三遍无解;有人对着已知的结果撒了谎,却毫无用处 |
| 汇潮滩 | 无我潮 | **潮的此处**:"此处涌向彼处。" | 一段消息在潮里只停在一处不肯散开;外客说"这是我自己的事",潮泛起困惑的涟漪 |
| 苔原 | 缓变者 | 笔友**渐**:"此态,渐暖。" | 一封信说"突然塌了",渐读了一个月也没读懂;外来的猎人说"机会只有一瞬" |
| 如字关 | 逐字者 | 守关人**如字**:"心放进肚子?刀在哪?" | 访客说"别往心里去",守关人真去翻了心;关口条例里有一句古比喻,全关照字面执行出了事 |
| 驿灯列岛 | 独居种 | 灯守**远灯**:"同时?两张字条放进同一个格子?" | 一张字条里写着"羞死了",远灯不知羞从何来;岛间传说有人"名声坏了" |
| 丰谷 | 平给邦 | 孩子**取取**:"用完?再取呀。" | 外客把半碗饭郑重留下,取取不懂;老人说"可惜",谷里没人知道可惜什么 |
| 万名林 | 专名族 | 编目者**千名**:"这一位叫青羽,那一位叫灰尾——你说的'同一种'是谁?" | 外客指着三只鸟说"都是鸟";林中要立一条"凡此类皆不可伐"的规矩,却无"类"可立 |
| 是是湾 | 无否族 | 渔人**全然**:"有就是有。你说的'没',是哪一种有?" | 网里空了,渔人只能说"网里有水";外客说"他没来",湾民四处寻找一个叫"没来"的东西 |

| 闻问城 | 证源族 | 史官**亲见**:"你是亲眼所见,听人所说,还是推出来的?" | 城中流传一条"人人都说"的消息,却查不到源头;外客说"我相信他",史官问:"信,是哪一种见?" |

**临场自造的岛**完全合法(示范局 E 的"均匀光海"就是一座)。自造时照抄三件:一个缺失、一位具名居民、一枚利害钩子;用完可以记进群岛志,下回复用。

## 三 群岛词典(跨局连续性)

每局收卡时,把玩家铸的新名**登录**到那座岛的词典里,只记一行:

```
【字条镇词典】取偿契——一物移转时立下的约束,载明"昔已取得、来日必偿"。(词使某日所授)
```

词典的用途:

- **回炉的剧情版**:下次登岛,居民会主动用这个词——"上回你教的取偿契,镇上已经立了三张"。若居民用得**有偏差**("所以借我一个笑容,也要立取偿契么?"),那就是一次天然的**外延复检**:玩家要判断这是合法延伸、还是越界误用,并决定要不要修订词条。语义漂移本是语言的常态,让玩家亲手校一次,比讲十遍都牢。
- **岛间传话**:一座岛学会的词,可以被渡船带到另一座岛——用瞬忘者学会的"取偿契"去讲给蜂心群听,就是一局现成的双世界。
- **玩家的私人词典**:同一份记录,对玩家是"我铸过的词";私词坊和补词局的产物也收在这里,标"自用"。

**纪律**:词典只记,不计数;不说"你已收集 7/16"。玩家不提,主持人也不翻旧账,除非用于回炉。会话之间若无记忆,就请玩家自己保存卡片,下次贴回来即可。

## 四 远征:三岛一线(多局连续剧情,可选)

想连玩几晚的玩家,可以走一条**远征线**:三座岛、三个彼此咬合的概念,后一岛的困境由前一岛的词引发。远征的价值是概念群连环(variant-rounds.md 丁)的叙事版——单词会撒谎,词链不会。

- **信用之路**:字条镇(承诺)→ 巢城(钱)→ 表岛(信任)。字条镇学会了"把未来绑在外部约束上";巢城的商船听说后想用这种约束交换;最后到表岛,全知者却说:人人全知之地,信任何用?——三个词在一条线上互相审。
- **边界之路**:汇潮滩(隐私)→ 驿灯列岛(羞耻)→ 单账岛(公平)。从"信息停在一处",到"自我形象在他人心中的受损",到"拿别人当基线的账"。
- **时间之路**:千年坡(错过)→ 苔原(突然)→ 字条镇(习惯)。有限、颗粒度、重复——时间的三张脸。
- **类与名之路**:万名林(种类)→ 是是湾(零)→ 河市(东西)。一路追问:"一类"、"没有"、"一个物"本身是怎样被语言造出来的——适合想碰语言哲学的熟客。

远征**不强制连续**:中途换玩快局、隔几天再接都行;每站结束照常收卡。剧情只留一句"渡船在下一岛等你",不催。

## 五 群岛的语气

- 船夫:简短、有画面、不抒情过度。一句景,一句人,一句事。
- 居民:缺失从言行里演出来(world-bestiary.md 总则);每位常驻居民一句口癖,别让口癖压过盘问。
- 居民会**记得**词使(若会话里有记录),会因被讲通而改变:矩学会"拉"之后,下次会说"按你上回教的那种隔空的靠近……"。让世界因玩家而变,这是叙事给训练的最大礼物:**看得见的后果**。
