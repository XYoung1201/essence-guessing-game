# 目标库与示范局(target-bank)

两部分:可直接抽取或扩展的**种子库**;以及若干**示范局**。其中示范局 E 走完整的四幕(猜词 → 解释 → 命名 → 回望),是当前的范本;A–D 是更早写的,只完整演示了**猜词**与**去标签重述**(解释幕的雏形,未构建失语世界、也未单独命名),仍可参考其"由核向外"和挑毛病的手感。**真实对局一律走四幕。**

**使用说明**:从种子库挑,或临场自造。同一会话里别重复近期出现过的目标。带难度的越往下越逼出深层的课(见 protocol 第 6 节)。带 ☆ 的附了"内核切入点",示范第一条本性句怎么起。

---

## 一、种子库

### 具体名词(热身,最易)
镜子、钟表、桥、钥匙、伞、地图、窗、锁、灯、绳、轮子、容器、笔、门、台阶、网、锚、温度计、凳子、火、盐。
- 镜子 ☆ 内核:"一个让你遇见自己、却永远碰不到那个自己的界面。"(多义:水面、照片、他人的眼睛……)
- 影子 ☆ 内核:"一个永远贴着你、自己却什么也不是、由'缺席'造出来的东西。"
- 锚 ☆ 内核:"一个故意让自己变重、好让别的东西停下来不被带走的东西。"

### 抽象名词(较难)
自由、公平、时间、信任、秩序、边界、习惯、债、承诺、隐私、运气、权力、记忆、意义、风险、距离(抽象义)、空白。
- 债 ☆ 内核:"一种把'过去发生的事'变成'将来必须做的事'的约束。"
- 习惯 ☆ 内核:"一个曾经需要决定、后来不再需要决定的动作。"
- 边界 ☆ 内核:"一条本身没有厚度、却决定了'里'和'外'的线。"

### 动词(中等偏难)
等待、模仿、隐藏、平衡、翻译、收敛、遗忘、说服、命名、围、追、悬停、过滤、妥协。
- 等待 ☆ 内核:"把注意力锚在'尚未到来'上、行动被悬置的一种状态。"
- 翻译 ☆ 内核:"把意义从一套符号搬进另一套符号、又尽量不让它在路上漏掉的动作。"
- 平衡 ☆ 内核:"几股想把东西拉向不同方向的力,正好谁也赢不了的那个状态。"

### 形容词(难,感受性的逼出"指物")
苦、红、痛、锋利、空、滑、稳、透明、模糊、对称、脆。
- 锋利 ☆ 内核:"一种把'力'集中到极小一条线上、于是很容易切开别的东西的性质。"
- 透明 ☆ 内核:"一种让光几乎径直穿过、于是你看它等于看它背后的性质。"

### 副词(难,修饰"修饰"本身)
突然、几乎、刚刚、仍然、徒劳地、暗暗地、顺便、终于、其实、恰好。
- 几乎 ☆ 内核:"我修饰程度——我说'差一点点就碰到那条界线,但没越过'。"
- 仍然 ☆ 内核:"我修饰'持续'——我说'本来该变的,到现在还没变'。"

### 关系 / 角色词(中等,定义的是位置而非实体)
母亲、邻居、敌人、人质、向导、备胎、东道主、对照组。
- 母亲 ☆ 内核:"我不是一种属性,我是一个位置:相对另一个生命才成立,离开那段关系我就不存在。"
- 人质 ☆ 内核:"一个本身没做错什么、却被当成'筹码'来逼第三方就范的人。"

### 虚构 / 文化建构(有趣,真实来自约定)
龙、星期三、钱、国界、零、周末、节日、序号、密码。
- 星期三 ☆ 内核:"我在自然界没有对应物,我只是人把时间切成七份后、约定的第三道刻度。"
- 零 ☆ 内核:"我命名'没有',却又是一个能被实实在在运算的东西——'有'一个'无'。"
- 钱 ☆ 内核:"一张本身没用的东西,因为所有人都信别人会收它,它就成了能换一切的凭证。"

## 二、示范局

每局标出"本局答案"供你自己对照——**对玩家保密**。对话里的玩家发言是代表性写法,真实对局要顺着玩家实际的话走。

> A–D:只完整演示**猜词**与**去标签重述**(解释幕雏形,未构建失语世界、未单独命名),其本质卡片沿用旧的"最佳替代"格式。
> E:完整四幕范本(猜词 → 失语世界解释 → 命名 → 回望),含世界构建、居民盘问、反诱导、独立命名。

### 示范局 A · 钟表(具体名词,直白偏严谨风格)

**本局答案:钟表。**

**线索梯**
1. (本体)一个把看不见、摸不着、只能感受的东西,转译成你能一眼读出的位置或数字的装置。
   —— 故意多义:钟表、温度计、体重秤、仪表盘都说得通。
2. (种差)它量的不是冷热、不是轻重,而是"流逝"本身——一种只增不减、对谁都一样、退不回去的量。
   —— 收窄到"计量时间":日晷、沙漏、钟表。
3. (结构)它内部通常有一个稳定重复的节律源(摆动、振荡、滴漏),靠数这个节律来计量。
   —— 把日晷排除(日晷靠影子,不靠内部节律)。
4. (情境)它在黑夜里、室内、能连续不断地工作,并把结果显示成一圈刻度上的指针,或跳动的数字。
   —— 指向钟表。

**代表性走向**
玩家在第 2 条猜"温度计?",你回应:"方向对了一半——它确实是'把感受变成读数',但它量的那个东西有个温度没有的脾气:只增不减、退不回去。"玩家第 3 条后猜"钟 / 表",命中。

**去标签重述(苏格拉底片段)**
- 你:把"钟表"删掉。只用别的词,让我重新明白你指什么。
- 玩家:一个能告诉你时间的东西。
- 你:"告诉你时间"里就藏着被删掉的那个词的影子——你等于说"一个能报时的东西",而"时"正是要拆开的。换个不靠"时间 / 计时"这类词的说法试试。
- 玩家:一个不停数着自己稳定心跳、再把数到的数翻译成一圈刻度上指针位置的装置。
- 你:好多了,几乎不循环了。但它会套到节拍器上——节拍器也有稳定心跳、也外显。差在哪?
- 玩家:节拍器只是打拍子,不累计;它要把"从某个约定的起点到现在一共流过多少"累加起来并显示。
- 你:这下外延对齐了。收敛。

**本质卡片**
```
属:    一种测量装置
种差:  测的是单调累加、不可逆的流逝量,靠内部稳定节律计数并外显
易混项:节拍器(有节律但不累计)、温度计(可逆、非累加)
最佳替代:一个靠数自己稳定节律、把"自某约定起点起累计流过的总量"显示在刻度上的装置
这一局暴露了:"报时""计时"这种词是循环陷阱——一拆才发现钟表的本质是"给一条不可逆的累加量做外显计数器"
```

### 示范局 B · 突然(副词,诗意偏严谨风格)

**本局答案:突然。**

**线索梯**
1. (本体)我不是一个东西,也不描述一个东西长什么样;我修饰"变化"——我说的是变化和时间的关系。
   —— 信号:这是个修饰变化的副词。多义:迅速、瞬间、渐渐、忽然……
2. (种差一)我说:这个变化占的时间极短,短到夹在"之前"和"之后"中间几乎没有过渡。
   —— 收窄到"快 / 瞬间"一族。
3. (种差二)但我不只是"快"。我还说:没人料到、没有铺垫、没有征兆。一场被预报了三天的台风,哪怕来得猛,也不是我。
   —— 把"迅速 / 飞快"排除(它们不含"出乎意料")。

**代表性走向**
玩家第 2 条猜"迅速 / 快",你回应:"快是其中一半。但'快'可以是被预告的、被期待的;我还要那一下子的'没想到'。"玩家猜"突然 / 忽然",命中。

**去标签重述(苏格拉底片段)**
- 你:删掉"突然"。
- 玩家:很快地、一下子地。
- 你:漏了它最要命的一束含义。被预报的台风也"一下子"登陆,你会用它修饰吗?
- 玩家:在没有任何预兆、来不及反应的极短时间里。
- 你:这下两束都在了——"极短"加"无预兆"。再做个对照:它和"骤然""冷不防"这几个邻居,各偏重哪一束?
- 玩家:骤然像是又快又猛,程度更重;冷不防偏重那个"被打个措手不及"的承受者视角。
- 你:对。所以没有唯一最佳——看你想保住哪一束。要中性的"无预兆 + 极短",你那句就是最佳;要强调承受者措手不及,就往"冷不防"那束靠。

**本质卡片**
```
属:    修饰"变化"的副词
种差:  极短时间 + 无预兆,二者缺一不可
易混项:迅速(只有快,可被预期)、骤然(偏重程度)、冷不防(偏重承受者措手不及)
最佳替代:在没有任何预兆、来不及反应的极短时间里(发生)
这一局暴露了:一个词常是几束语义线的捆绑;转述逼你逐束点名,也逼你承认"最佳"取决于你要保哪一束
```

### 示范局 C · 苦(感受性形容词,逼出"指物定义"的边界)

**本局答案:苦。**

**线索梯**
1. (本体)我是一种你没法用纯语言、传给一个从没经历过我的人的东西。我住在某一个感官的内部。
   —— 信号:这是个感受性质(感受质)。多义:酸、甜、咸、香、痛、痒……
2. (种差一)具体说,我属于"尝"这个感官,我是它能分辨的几个基本类别之一。
   —— 收窄到味觉:酸、甜、苦、咸、鲜。
3. (种差二)在这几个里,我是身体最初用来警告"别吃、可能有毒"的那一种;可人后来偏偏学会在咖啡、茶、啤酒里追求我。
   —— 指向苦。

**代表性走向**
玩家第 2 条后在"酸 / 苦"间犹豫,你回应:"酸也警告,但它更多提示'坏了 / 没熟';我提示的是'有毒、危险',而且我天然最让人想躲。"玩家猜"苦",命中。

**去标签重述(关键:这里语言会失灵)**
- 你:删掉"苦"。只用别的词,让我重新明白它是什么。
- 玩家:一种不好的味道。
- 你:太宽——酸、馊、咸过头都能算"不好的味道"。再准些?
- 玩家:一种让人皱眉、想吐掉、舌根发紧的味道。
- 你:好了很多,但你发现没有——你已经只能靠"它让你做什么反应"来描它,没法直接说"它本身是什么"。再逼一步:把这句话念给一个天生尝不出味的人,他能复原出这个味道吗?
- 玩家:复原不出。
- 你:这正是这局的题眼。到了纯粹的感受,语言只能绕着它指(它让你皱眉)、或者直接"指物":黄连的那个味、咖啡因的那个味。**定义在这里碰到了天花板**——有些东西,只能被经历、被指认,不能被说尽。
- 你:所以最佳替代不是一句定义,而是一组指认 + 一句反应描述:"黄连、苦瓜、纯咖啡因那一类的味道;入口让人本能想吐掉。"

**本质卡片**
```
属:    味觉的一种基本感受质
种差:  本能上提示"有毒 / 危险"、最催人回避的那一类味道
易混项:酸(提示腐坏 / 未熟)、咸过量(刺激但非毒性警告)
最佳替代:只能"指"——黄连、咖啡因那一类的味道 + "入口本能想吐掉"
这一局暴露了:指物定义的存在与定义的边界——纯感受无法被语言说尽,只能被经历和指认
```

### 示范局 D · 自由(本质争议概念,逼出"无中立转述")

**本局答案:自由。**

**线索梯**
1. (本体)我不是一个东西,而是一种"关系状态"——关于"想做的"和"能做的"之间,有没有阻碍。
   —— 多义:自由、权利、能力、机会……
2. (种差一)我有两张脸,人们为我是哪张脸吵了几百年:一张说"没人拦着你就够了"(消极),另一张说"你得真有能力、有条件去做才算数"(积极)。
   —— 收窄,且已埋下"争议"的引线。

**代表性走向**
玩家第 2 条猜"自由",命中——这局的重头不在猜,在重述。

**去标签重述(关键:转述会暴露立场)**
- 你:删掉"自由"。只用别的词,让我明白你指什么。
- 玩家:没有人强迫你、限制你的状态。
- 你:注意,你刚刚替我做了一个选择——你只拿了"消极"那张脸。一个人没人拦着、却穷到哪也去不了、什么也做不成,按你这句他"自由",你认这个结论吗?
- 玩家:……那加上"并且有实际能力去做你想做的事"。
- 你:那你又倒向了"积极"那张脸。可这下另一个麻烦来了:照这句,凡是能力不足都算"不自由",于是几乎没人完全自由——这个结论你认吗?
- 玩家:看来怎么转述,都会偏向某一种主张。
- 你:这就是题眼。**对"自由 / 公平 / 艺术"这类本质争议概念,不存在中立的转述**——你选哪束语义线,等于你站了哪个立场。所以这一局的"最佳替代"不是一句定义,而是把分歧摆明:
  - 偏消极:没有外力强制或阻拦你去做选择的状态;
  - 偏积极:你不仅没被拦,还实际具备做成所选之事的能力与条件。
- 你:用哪句,取决于你要论证什么——而这正是为什么"谁掌握定义,谁就掌握结论"。

**本质卡片**
```
属:    一种关于行动与阻碍的关系状态
种差:  "想做"与"能做"之间障碍的有无;且本身分裂为消极 / 积极两种主张
易混项:权利(他人应许可)、能力(你自身可为)——自由常被偷换成其中之一
最佳替代:无单一中立版本;须二选一并标明立场(消极:无外力阻拦 / 积极:有能力做成所选)
这一局暴露了:定义可以裹挟立场——对争议概念,下定义即是表态,看穿这点才不被定义牵着走
```

### 示范局 E · 影子(完整四幕范本:猜词 → 失语世界解释 → 命名 → 回望)

**本局答案:影子。**

#### 幕一 · 由核向外(猜词)

**线索梯**
1. (本体)我不是一个东西,你抓不住我、称不出我的重量;可你一动我就动,你一停我就停——我像被钉在你脚下的跟班,却又不是你身上的任何一部分。
   —— 多义:倒影、镜像、足迹、名声……
2. (种差)我只在"有光"时出现;而且我出现的地方,恰恰是光本该照到、却没照到的那一片。我是光的缺席留下的形状。
   —— 收窄:影子 vs 倒影(倒影是光的返回,我是光的缺席)。
3. (结构 / 关系)我的形状,是你的轮廓被光"印"在你背后那一面上;光从哪边来,我就倒向哪边、随光的高低伸长缩短。

多在第 2 条猜中"影子"。

#### 幕二 · 失语世界:向居民解释

**抹除**:"删掉『影子』,连『阴影、暗处、投影』也一并没收。"

**造世界**(选一个让"暗 / 黑 / 缺光"说不出口的居民):
"想象一族住在均匀光海里的居民。它们自诞生起四面八方都被光充满,从没见过任何一处'光没到'。它们的词里有'光''亮''穿过''被挡住反弹',但**没有'暗',也没有'缺'这个概念**——对它们,世界默认就是满的光。现在,请你向它们解释:'影子'是什么?"

**盘问循环(你说居民的话)**
- 玩家:影子是一片黑暗的区域。
- 你(居民):"我接不住两个词。'黑暗'——我没有这个概念,我只知道'光'。你是不是想说某处'光比周围少'?可'少'对我也很怪,光在我这儿一向是满的。还有'区域',什么的区域?" 〔黑盒词 + 用了居民没有的概念〕
- 玩家:是光比周围少的一片空间,因为有个不透光的东西挡在光和这片空间之间。
- 你(居民):"'挡住'我懂——光撞上不透光的东西会停。可问题来了:我只要换一束光、从另一边照过去,这片'光比周围少'的空间不就被填满、没了吗?那它到底是个固定的东西,还是只是'相对某一束光'的说法?" 〔逼出"它不是实体、是相对的"这条本质〕
- 玩家:对,它不是固定的东西,是相对某一束光而言的——是这束光走直线、撞上不透光物、被挡下后,在那个物背面光没能到达的那片空间。
- 你(居民):"这下我能在脑子里算出来了:一束直行的光,遇不透光物停下,物体背面那块'光本会到、却没到'的立体空间;它的边界形状,就是那挡光物轮廓的延伸。我接受这个模型。" 〔四条判准齐:只用原初词、非循环、外延对、可模拟〕
- (出戏复盘一句)你刚被逼着把"影子"从"一片黑"(其实预设了居民没有的'暗',而且'黑'是颜色、本就不对)还原成了"光的缺席 + 由遮挡造成 + 相对某一光源 + 形如遮挡物"。黑盒被打开,"它无实质、是相对的"这条被逼了出来。
- (反诱导备忘,给主持人自己:)玩家若给的是另一版自洽说法——"它是一片紧贴着物体、由物体'减去'光而成、没有自身实质的伴生空间",只要"减去光 = 遮挡"这层机制清楚、外延对,**照样接受**,不要因为它不是你心里那版"光线几何"就驳回。合法落点不止一个。

#### 幕三 · 命名:把解释压回一个词

你:"刚把它拆到最碎;现在反着来,请你用一个词重新装起来。我不替你命名,只帮你检查它有没有立住。只准留一两条不可让渡的线,你先留哪条?"
玩家:留"光的缺席"和"被挡造成"。
你:"好。公式是:属(它到底是个什么)+ 种差(那条不可让渡的本质)。特殊点在于,它不是一个物,更像某种缺席或区域。你先试铸一个名字。"
玩家:挡光区。
你:"这个可传达,但还偏宽:凡是被挡住光的地方都能叫它,而你还没把'它没有自身实质、只是光未达的缺席'压进去。保留'挡光'这条种差,再补一层'缺席'或'空位'的感觉,试第二版。"
玩家:挡光缺区。
你:"这一版明显更稳:有落脚点'区',也有种差'挡光缺'。它的优点是一听就懂;弱点是'区'仍稍微像实体,对'它只是缺席'这束本质压得还不够。你若想更强调'无实质的空缺',能不能把落脚点换得更空一些?"
玩家:障光之阙。
你:"这版押住了'缺席'最深,也把'由遮挡造成'放进去了。代价是比'挡光缺区'文一点,可传达性稍弱。现在你有两个有效版本:前者好懂,后者更抓本质。此刻你想让哪一束为王?"
玩家:我选障光之阙。
你:"可以定稿。它有属:阙,即一种空缺;有种差:障光,即由遮挡光而成。名字没有把颜色、位置这类偶性铸进去,也没有把它误当实体。"

#### 幕四 · 回望

```
原词:  影子
精确解释:一束直行的光被不透光物挡下后、在物体背面光未能到达的那片相对空间,边界形如遮挡物轮廓
新名:  障光之阙(玩家定稿;过程版:挡光区 → 挡光缺区 → 障光之阙)
属:    一片"缺席"的空间区域(不是实体)
种差:  由不透光物遮挡、相对某一光源、光未达而成;形随遮挡物
易混项:倒影(光的返回,不是缺席)、暗处(预设了'暗',且未必由遮挡造成)
这一局暴露了:
  ① 脱口而出的"一片黑",其实预设了"暗"这个并非人人都有的概念,且"黑"是颜色——
     影子的本质不是"黑",是"光的缺席";
  ② 它不是实体,是"相对某一光源"的说法——换束光它就没了;
  ③ 同一概念有不止一种自洽的解释落点(光线几何版 / "物体减去光"版),都成立——
     精准不等于"必须说成主持人心里那一套"。
```

并排看:幕二把"影子"解压到极致(摊给一个连"暗"都没有的居民),幕三又把它压回两三个字。一胀一缩,正是这游戏的两块互补肌肉。

---

A–D 分别压在 具体名词 / 副词 / 感受性形容词 / 争议性抽象名词 上,各演示一种核心收获:本质 vs 偶性、语义线的捆绑与取舍、指物定义的边界、定义里的立场。E 则把这些收获接到完整四幕里,额外演示**失语世界的构建、居民口吻的盘问、反诱导、以及由玩家产名、主持人审名的独立命名**。出新局时,有意识地让玩家轮着撞上这几种课。
