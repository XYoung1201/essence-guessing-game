# 快局十二种(quick-games)

单肌肉隔离训练。前七种是三代的老班底,第八到十二种是四代新增(分别取自原型理论、框架语义、概念隐喻、结构映射、语义演变,学理见 learning-science.md)。每局 5–15 分钟,可单开、可串烧、可垫在主线前后当热身或加餐。共用主线的毛病词汇表(黑盒 / 循环 / 太宽 / 太窄 / 偶性当本质 / 后果当定义 / 立场走私——诊断措辞见 definition-tools.md)。通用纪律:一次一步;只挑真毛病;判准到了就收,不为刁难续命;全程自然散文。

## 1 划界快攻(练外延精度)

**怎么跑**:选一个概念(玩家点或你挑)。你连发 6–10 个边缘案例,一个一个来;玩家每题判"算 / 不算"并给一句理由。你私下记**台账**:玩家每条理由都是一条临时判据,后续案例要么顺着他的判据出更难的题,要么故意造一个让他的两条判据打架的案例。出现矛盾就当场摊开:"第 2 题你凭'供人通行'拒了彩虹,第 6 题没人走过的倒树你又收了——哪条作废?"

**案例怎么造**(任选几招):换材质留功能;留形状抽功能;降级到天然物;升级到比喻义(网线算桥吗);制度化版本;残骸(断桥还叫桥吗);潜在而未用;移动版(摆渡船);极端尺度。

**收束**:玩家能用一句话说出最终判据,且它对前面所有案例给出一致裁决(允许他宣布"第 3 题我改判")。

**示例(桥)**:独木横溪 → 跨海大桥 → 过街天桥 → 隧道(连接两岸,但不跨于其上?)→ 摆渡船(移动的通路算吗)→ 彩虹(形似而无通行)→ 恰好倒在两岸间、从没人走过的树(潜在性算不算)→ 断桥(功能已失,名还在?)。

**种子**:桥、门、武器、家具、礼物、谎言、工作、运动、乐器、垃圾、文物、玩具。

## 2 真假定义(练审辨——受方肌肉)

**怎么跑**:你选一个概念,私下铸三个定义:一个**大体能立**(留一处小瑕),两个各埋一种**典型病**(太宽 / 太窄 / 循环换皮 / 黑盒 / 立场走私 / 偶性入定义 / 后果当本质,挑两种埋)。摆出来,玩家逐个验伪:**叫出病名 + 给出一个反例或指认走私点**。验完,让玩家把最好的那版**修到能立**,你再补一个新反例试它。

**收束**:三版的病灶都被点名且有据;修复版扛得住你最后那个反例。

**示例(谎言)**:版一"与事实不符的话"——太宽:记错了的话、小说台词、演员念白全中招,漏了"明知为假 + 意在使人信"。版二"为了害人而说的假话"——太窄,且把动机偶性铸进了定义:善意谎言、为脱身撒的谎全漏。版三"懦弱者操纵他人的手段"——立场走私:属里塞了判罪,定义未下先定性。修复方向:明知为假、以使对方相信为图、以断言形式说出。彩蛋追问:句句属实却故意误导的话,算不算?

**种子**:谎言、勇敢、艺术品、朋友、浪费、教育、效率、自律、传统、运气。

## 3 近邻分茎(练精细分辨——选词的手感,最直接补益日常表达)

**怎么跑**:摆一对(或一组三个)近义词。玩家先押一条**种差假设**("我觉得差在……")。你用**代入测试**证伪:造句子,空一格,问哪个词放得进、哪个放进去会变味——"他很享受这份____""人群越热闹,他越觉得____"。每个测试句只打一条假设。来回到玩家的种差能解释全部代入结果为止。

**收束**:一句分界 + 每个词各举一块**独占领地**(只有它能站住的句子)。

**示例(孤独 / 寂寞)**:"享受孤独"成立、"享受寂寞"别扭 → 寂寞自带匮乏的负价;"人群中感到寂寞"与"在人群中保持孤独"都通但义不同 → 孤独可以指一种可选择的独处姿态(状态),寂寞是联结缺失之感(情绪)。分界:一个是处境与姿态、价中性、可主动;一个是匮乏感、负价、被动降临。

**种子**:孤独 / 寂寞;羡慕 / 嫉妒 / 妒忌;后果 / 结果 / 效果;边界 / 界限 / 底线;习惯 / 惯性 / 瘾;忍耐 / 忍受 / 容忍;信任 / 信赖 / 信仰;内疚 / 羞耻 / 后悔;希望 / 期待 / 盼望;冷静 / 冷漠 / 冷淡;勇敢 / 大胆 / 鲁莽;节俭 / 吝啬;自信 / 自负 / 自尊;怀疑 / 质疑 / 猜疑;严格 / 严厉 / 苛刻;安静 / 寂静 / 沉默;责任 / 义务 / 本分;看 / 望 / 盯 / 瞥。

## 4 圈内圈外(练归纳——自下而上那支箭,主线完全没有的方向)

**怎么跑**:你私下定一个隐藏概念(不说词),备好私卡:圈内实例 5 个、圈外近邻实例 4 个,都写成一两句的小场景。先亮 3 内 2 外;玩家提出共相假设;你再亮**专打他假设**的新实例——他的规则会误收的圈外例、会漏掉的圈内例。玩家可以反问三次"这个场景算吗?"。

**收束**:玩家给出能裁对全部实例的定义;愿意的话再压成一名,然后揭词。

**示例(人情债)**:圈内——婚礼随了八百的同事请你帮忙搬家;邻居常帮你收快递,你买水果总"顺手"带一份;上次他替你顶了班,这次他孩子升学宴你不敢不去。圈外——银行贷款(有合同有数额);陌生人扶你一把(单次,不进账本);明码标价的跑腿(即时两讫)。共相要逼到:无合同、不计价,却**双方都记着账**,且以亏欠感驱动回报的时机与分量。

**种子**:人情债、仪式感、沉没成本、给台阶、分寸、默契、内耗、面子、安全感、边界感。(补词局的无名现象种子也可以拿来这么玩,见 variant-rounds.md。)

## 5 立场炼金(练修辞免疫——亲手看见定义如何成为武器)

**怎么跑**:选一个争议词。玩家写两版定义:**褒版**(让它显得正当甚至高尚)与**贬版**(让它显得可鄙),各一两句。然后**验尸**,逐版指认结论走私在哪:属的选择?带评价的修饰词?外延裁剪(只圈进有利案例)?隐含因果?被动语态把主语藏了?接着做**钢人步**:挑玩家自己更反感的那一版,问"持这个立场的人,会认这是自己的说法吗?"——不认,就改到对方会点头为止;批评要打在真靶子上,不打稻草人。最后做**中立尝试**:写一版尽量不带立场的,并诚实回答它牺牲了什么——常常是把最有争议的那块切掉了,变得乏味或空心;这本身就是一课。

**铁律**:必做双向 + 验尸,绝不停在单边的武器化定义上。这局的产出物是免疫力,不是弹药。

**收束**:两版的走私点各被点名;钢人版过了"对方会认"这一关;中立版的代价被说出口。

**种子**:加班、内卷、躺平、补习班、彩礼、酒局、滤镜、房贷、跳槽、佛系、断舍离、网红、流量、算法推荐。

## 6 限字压缩(练取舍——信息排序即价值排序)

**怎么跑**:起点是一段已被接受的精确解释(主线幕二的产物,或现场对一个概念先速写一版)。然后下阶梯:压到 **40 字** → **20 字** → **8 字** → **一个词**。每一级你只做两件事:问"这一刀砍掉了哪条线?",再用一个反例试外延还守不守得住。守不住时,玩家可以换砍别处,但不许加字。

**收束**:到一词级,自然接上命名公式(属 + 种差);收尾让玩家复述自己的取舍序列——哪条线最先死、哪条撑到最后,**那就是他心里的本质排序**,这局最值钱的产出。

**种子**:任何刚玩过主线的概念最佳;冷启动可用:钥匙、排队、道歉、保险。

## 7 喻体铸造(练生动而不失真——表达的另一半)

**怎么跑**:给定一个已说清机制的概念,请玩家为一个十岁孩子铸**一句比方**。然后列**映射表**:源域的哪些件对应靶域的哪些件;再找**误导边**——这个比方会让孩子在哪个问题上答错?玩家修补,或干脆**圈定失效边界**("这个比方只解释 X,不解释 Y")。

**收束**:比方和它的失效边界**一起**说出口,才算一枚诚实的比方。

**示例(通胀)**:"钱像游乐园代币:园里突然多发一倍代币,棉花糖还是那么多,每枚代币能换到的就少了。"映射表对得上"币多物少则贬";误导边:游乐园是封闭的、代币只有园方能发,这比方答不了"为什么有时增发却不通胀"。把失效边界声明出来,这枚比方就能用了。

**种子**:通胀、重力、递归、免疫、利率、熵、带宽、过拟合、复利、外部性。

## 8 典型度阶梯(练原型与边界之分——"像不像"与"算不算"是两回事)

**怎么跑**:选一个类别词,你摆出 6–8 个成员(含一两个"冒名者"——像却不是,如鸟类里混进蝙蝠)。玩家先**凭直觉**把它们从"最像"排到"最不像";再拿出(或现写)一条定义,逐个裁"算 / 不算"。两张榜并排一看,总会出现错位:排在末尾的企鹅是真成员,排在中间的蝙蝠却不算。追问:"你的直觉榜靠什么排的?定义靠什么裁的?"

**收束**:玩家亲口说出"典型度靠的是 ×× 特征的多少,成员资格靠的是 ×× 这一条"——原型管识别,定义管边界,两者各司其职。

**示例(鸟)**:麻雀、鸽子、鸡、鸵鸟、企鹅、蝙蝠、几维鸟。直觉榜:麻雀最像,企鹅、几维鸟垫底,蝙蝠居中;定义裁决(有羽毛、卵生的恒温脊椎动物……):企鹅、几维鸟全收,蝙蝠出局。错位正好暴露"会飞"是原型特征、不是成员条件。

**种子**:鸟、家具、水果(番茄算吗)、运动(下棋算吗)、工具、武器、蔬菜、游戏、朋友、病。

## 9 框架补位(练完整——一个动词背后站着一整台戏)

**怎么跑**:选一个动词或事件词。玩家先列出这件事里**必须在场的角色**(谁做、对谁、用什么、换来什么、在什么前提下、事后什么变了)。你逐个拿掉一个角色,问"还是这件事吗?"——拿掉就散的,是框架的承重角色;拿掉仍在的,是可选角色。最后,让玩家只用承重角色写一句定义。

**收束**:一张承重角色清单 + 一句不漏角色的定义。常见惊喜:玩家最初漏掉的那个角色,正是这个词和它近邻的分界线。

**示例(借)**:出借方、借入方、物、**归还的预期**、期限(可选)、利息(可选)。拿掉"归还的预期",借就塌成了"给";拿掉期限,仍是借。于是"借 / 给 / 租 / 偷"四兄弟的分界,全落在"归还预期"与"对价"两个角色的有无上。

**种子**:借、教、原谅、背叛、道歉、贿赂、介绍、等待、救、骗、送礼、投票。

## 10 隐喻考古(练看见语言里的暗桩)

**怎么跑**:选一个抽象概念(时间、争论、爱、思想、生命、注意力)。玩家先**挖**:写出十句日常里说这个概念的习惯话("花时间、省时间、浪费时间、时间不够用"),然后归纳出底下那条**系统性隐喻**("时间是一种可以花费的资源")。再做两件事:一是列出这条隐喻**偷偷带进的推论**(时间可以存吗?可以借吗?——日常话里有"借我五分钟",却没有"存一点时间");二是**换一条隐喻**重新说这个概念("时间是一条河"),看哪些推论跟着变了。

**收束**:玩家说出一条隐喻、它带进的一条推论,以及换隐喻后那条推论怎么变了。这一局与逐字者是一对:逐字者把隐喻当真执行,这里把隐喻挖出来看。

**种子**:时间、争论、爱、思想、生命、注意力、情绪、记忆、权力、知识、关系、经济。

## 11 同构猎手(练远类比——在八竿子打不着的地方认出同一副骨架)

**怎么跑**:你给一个已经说清机制的概念(或刚玩完主线的目标),玩家去**三个相距尽量远的领域**(自然、机械、社会、心理、游戏、语言……)各找一个**关系结构相同**的东西。每找到一个,画一行映射("保险丝的'最先到门槛'↔ 壁虎尾巴的'预设断点'")。然后你挑一个,问:"它在哪一条关系上其实不同构?"

**收束**:三个远亲 + 各一行映射 + 至少一处诚实的"这里不同构"。能在远处认出同一副骨架,是迁移能力最直接的标志。

**示例(保险丝:以自毁换全局之存)**:汽车溃缩区(机械)、壁虎断尾(自然)、棋局弃子(游戏)、公司里替大家背锅的"防火墙部门"(社会)。不同构处:壁虎尾巴会再生,保险丝不会;弃子有意图,保险丝无知无觉。

**种子**:保险丝、锚、疫苗、脚手架、催化剂、过滤器、杠杆、种子、面具、门槛、回声、发酵。

## 12 义变追踪(练意义是活的——一个词的一生)

**怎么跑**:你给一个**你确有把握**的词义演变案例:先亮今义,再亮古义或旧义的一两个用例(只亮用例,不说"它以前是什么意思")。玩家先从用例推出旧义,再判断演变**类型**(扩大 / 缩小 / 转移 / 褒贬升降)并猜**机制**(哪一步隐喻、哪一步转喻、哪一次社会变化把它推走了)。

**专属铁律**:只用主持人有把握的案例;拿不准的明说或换题,与词源对照同一纪律,绝不现编。

**收束**:玩家说出类型、一条合理机制,并顺手回答一问:"今天这个词,有没有正在发生的新演变?"——把眼光接到眼前的语言。

**有把握的例子**:江、河(专名→通名,扩大);臭(气味→难闻之气,缩小);走(跑→步行,转移);爪牙(得力助手→帮凶,贬降);牺牲(祭祀用的牲畜→为某目的舍弃生命或利益,转移);网(捕鱼之网→互联网,隐喻扩展)。

## 串烧套餐

- **炼字之夜**:近邻分茎 ×2 → 主线一局(带雅名,见 protocol 3.5)。
- **审官之夜**:真假定义 → 立场炼金 → 实战检验(主线幕四那招单拎出来,见 protocol 4.5)。
- **造词者之路**:圈内圈外 → 补词局 → 私词坊(后两者见 variant-rounds.md)。
- **认知科学之夜**(四代):典型度阶梯 → 框架补位 → 同构猎手,看见"类、事件、结构"三种概念骨架。
- **语言侦探之夜**(四代):隐喻考古 → 义变追踪 → 主线一局(叠逐字者)。
- **五分钟晨练**(四代,独自也可以):挑今天听到的一个词,只做三件事——它的属是什么、它最近的邻居是谁、它们差在哪一条。
