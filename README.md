# 猜词 · 解释 · 命名

一个用于训练本质识别、精确定义与命名能力的 AI 互动游戏技能。

玩家先从由内向外的线索猜出一个词,再把这个词解释给一个"唯独没有此概念"的世界,最后把已经拆开的解释重新压缩成一个新名字。它看起来像猜词,真正训练的是:如何看穿词语背后的结构,如何把模糊直觉变成别人也能复现的定义。

## 这个项目能给你什么

- **把"我大概懂"变成"我说得清"**:游戏会逼你拆开黑盒词,补上机制、边界和例外,让理解从感觉变成可检查的表达。
- **训练定义能力,而不是背定义**:你不会被标准答案牵着走,而是在一次次追问中自己找到属、种差、外延和易混项。
- **提升写作、教学、产品和研究中的概念清晰度**:当你需要解释一个抽象词、设计一个命名、澄清一个需求或拆解一个争论时,这套玩法能帮你更快抓住"真正不可让渡的那条线"。
- **增强抗框架能力**:很多词会偷偷携带立场、价值判断或边界设定。游戏会让你看见定义如何影响结论,减少被现成说法带着走。
- **让语言练习变得有趣但不黏人**:没有积分、连胜和排行榜,重点是每一局结束时多看清一点。

## 玩法速览

### 幕一:猜词

主持人秘密选定一个对象,从最核心的本质开始给线索,逐层向外展开。玩家可以猜,也可以要求继续。

### 幕二:解释

猜中后,主持人构建一个缺少该概念的世界。玩家必须用这个世界的居民听得懂的话解释目标。主持人扮演居民,挑出循环、含糊、过宽、过窄或依赖缺失概念的地方。

### 幕三:命名

玩家把已经解释清楚的概念重新压缩成一个新造词。主持人只负责审名、追问和指出边界问题,不直接替玩家给答案。

### 幕四:回望

回看这一局暴露了什么:哪些是本质,哪些只是偶然特征;这个词如何切分世界;新名字保留了什么,舍弃了什么。

## 谁适合用

- 想提升表达、定义、概念分析能力的人
- 写作者、教师、研究者、产品经理、咨询顾问
- 想用游戏方式练习批判性思维和语言精度的人
- 正在制作 AI 角色、技能或教学活动的人

## 安装与使用

### 作为 Codex 技能使用

把本仓库克隆到你的 Codex skills 目录下:

```powershell
git clone https://github.com/XYoung1201/essence-guessing-game.git "$env:USERPROFILE\.codex\skills\essence-guessing-game"
```

然后在 Codex 或支持技能调用的环境里说:

```text
玩那个游戏
本质游戏
猜词解释命名
拆词重构
开一局 essence game
```

### 作为提示词资料使用

如果你的环境不支持直接安装技能,也可以把 `SKILL.md` 作为主规则,并在开局前读取:

- `references/game-protocol.md`:四幕玩法的详细运行手册
- `references/target-bank.md`:目标库和完整示范局
- `references/definition-tools.md`:定义、外延、属种差、框架陷阱等分析工具

## 一局会长什么样

```text
主持人: 第一层:它把还没有发生的行动提前放进现在,让别人可以把你的未来当作某种依据。

玩家: 承诺?

主持人: 猜对了。

接下来把"承诺"这个概念从语言里删掉。现在有一个世界,那里的人知道人会说话、会计划、会改变主意,但他们没有"承诺"这个概念。请你不用这个词,让他们明白:这到底是一种什么东西?
```

真正的价值从这里开始:玩家给出的解释会被居民追问,直到它不再靠黑盒词撑住。最后玩家再把这段解释铸成一个新的名字。

## 设计原则

- 从本质而不是外观开始
- 一次只推进一小步
- 只指出真实毛病,不把玩家拖向主持人心里的标准答案
- 命名必须由玩家产出
- 允许一个概念有多条自洽的解释路径
- 反馈服务于洞察,不服务于上瘾
