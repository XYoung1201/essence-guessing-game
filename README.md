# 猜词 · 解释 · 命名

一个用于训练本质识别、精确定义与命名能力的 AI 互动游戏技能。

玩家先从由内向外的线索猜出一个词,再把这个词解释给一座"唯独没有此概念"的岛上的居民,最后把已经拆开的解释重新压缩成一个新名字。它看起来像猜词,真正训练的是:如何看穿词语背后的结构,如何把模糊直觉变成别人也能复现的定义。

## 这个项目能给你什么

- **把"我大概懂"变成"我说得清"**:游戏会逼你拆开黑盒词,补上机制、边界和例外,让理解从感觉变成可检查的表达。越熟的词,越容易高估自己懂它——开讲前后各报一次把握,你会亲眼看见这个落差。
- **训练定义能力,而不是背定义**:你不会被标准答案牵着走,而是在一次次追问中自己找到属、种差、外延和易混项。
- **提升写作、教学、产品和研究中的概念清晰度**:当你需要解释一个抽象词、设计一个命名、澄清一个需求或拆解一个争论时,这套玩法能帮你更快抓住"真正不可让渡的那条线"。
- **增强抗框架能力**:很多词会偷偷携带立场、价值判断或边界设定。游戏会让你看见定义如何影响结论,减少被现成说法带着走。
- **让语言练习变得有趣但不黏人**:有一个有名有姓的世界、有会记得你的居民,但没有积分、连胜和排行榜,重点是每一局结束时多看清一点。

## 玩法速览

### 主线四幕

1. **猜词**:主持人秘密选定一个对象,从最核心的本质开始给线索,逐层向外展开。
2. **解释**(关键幕):主持人在失语群岛上造一个缺少该概念的世界,扮演具名的居民,挑出你解释里的循环、黑盒、过宽、过窄、漏角色,或依赖了居民没有的概念之处,直到居民能在脑子里把它跑一遍。最后居民会把你的意思整理成一段逻辑完整、特征齐全的**范本复述**,可以直接拿去讲给不知道这个词的人听,也是你学习表达的样板。
3. **命名**:你把已经解释清楚的概念重新压缩成一个新造词(属 + 种差,或命名六刀里的另一把)。主持人只审名、追问和做"字面冷读",不替你给答案。
4. **回望**:哪些是本质,哪些只是偶性;这个词如何切分世界;它替谁干活;若它从未被造出,世界会少什么。最后收一张本质卡片,并把新名登录进那座岛的词典。

### 快局十二种(5–15 分钟)

划界快攻、真假定义、近邻分茎、圈内圈外、立场炼金、限字压缩、喻体铸造、典型度阶梯、框架补位、隐喻考古、同构猎手、义变追踪。

### 变体十局

异语寻宝、补词局、私词坊、概念群连环、无核局、造界局、双世界、概念嫁接、错词使节、群岛远征。

### 失语群岛

十六族居民各守一岛:只懂直线与碰撞的矩港、十息之外尽数遗忘的字条镇、每片叶子都有专名却没有"类"的万名林、语言里没有"不"字的是是湾、每句话都要标明"你怎么知道"的闻问城……每座岛有一位常驻居民和他们此刻需要这个词的理由。

## 四代设计依据(简表)

| 角度 | 吸收了什么 | 落在游戏哪里 |
|---|---|---|
| 认知科学 | 解释深度错觉、原型理论、结构映射、概念整合、提取与间隔练习 | 校准一问、典型度阶梯、同构猎手、概念嫁接、回炉与群岛词典 |
| 心理学 | 信息缺口与好奇心、心流、最近发展区与脚手架、校准与元认知、心理安全 | 悬念曲线、心流信号表、锦囊三级、自信刻度、教练式反馈 |
| 叙事学 | 叙事是理解的格式、人物与视角、后果与连续性、悬念与转折 | 失语群岛、世界开场三笔、利害钩子、封印一问、远征 |
| 语言学 | 自然语义元语言、框架语义、概念隐喻、言语行为、汉语构词法、语义演变、弱版语言相对论 | 原初模式、框架补位、隐喻考古、恰当条件、命名六刀、义变追踪、异语寻宝 |
| 思维训练 | 苏格拉底诘问、钢人论证、可证伪预测、概念工程、反事实 | 居民盘问、立场炼金钢人步、封印一问、回望新问 |

完整说明见 `references/learning-science.md`(给主持人看;游戏对话里不讲这些术语)。

## 安装与使用

### 作为 Codex 技能使用

把本仓库克隆到你的 Codex skills 目录下:

```powershell
git clone https://github.com/XYoung1201/essence-guessing-game.git "$env:USERPROFILE\.codex\skills\essence-guessing-game"
```

### 作为 Claude 技能使用

把仓库文件夹放进你的技能目录(或打包上传),`SKILL.md` 即入口。

然后在支持技能调用的环境里说:

```text
玩那个游戏
本质游戏
来个快局
失语群岛
开一局 essence game
```

玩的过程中随时可以说"口令",查看提示、换族、跳幕、调难度、收卡等指令。

### 作为提示词资料使用

如果你的环境不支持直接安装技能,也可以把 `SKILL.md` 作为主规则,并在开局前读取 `references/game-protocol.md`;需要时再读其他册子。

## 一局会长什么样

```text
主持人: 第一层:它把还没有发生的行动提前放进现在,让别人可以把你的未来当作某种依据。

玩家: 承诺?

主持人: 猜对了。把"承诺"连同它的近义词一并从语言里删掉。

渡船靠上字条镇。镇口贴满了字条,风一吹哗啦啦响。字条婆婆冲你愉快地挥手:"你好!咦,你手里这张字条,怎么是我的笔迹?"镇上今早吵了一架:有人拿着一张字条要别人"兑现",被要求的人一脸茫然。

开讲前凭直觉报个数:一到五,你觉得自己能把它讲清楚到什么程度?
```

真正的价值从这里开始:你给出的解释会被居民追问,直到它不再靠黑盒词撑住。最后你再把这段解释铸成一个新的名字,登录进字条镇的词典。

## 设计原则

- 从本质而不是外观开始
- 一次只推进一小步
- 只指出真实毛病,不把玩家拖向主持人心里的标准答案
- 命名必须由玩家产出
- 允许一个概念有多条自洽的解释路径
- 戏不压练:世界是为训练服务的
- 反馈服务于洞察,不服务于上瘾

## 版本沿革

- **一代**:两幕(猜词 + 抹除替代)。
- **二代**:四幕主线成形(猜词、失语世界解释、命名、回望);英文协议与工具箱。
- **三代**:七种快局、七种变体、十二族居民、窍门图谱与陷阱档案,全面中文化。
- **四代**:失语群岛世界观与群岛词典;学理底座;新增五种快局、三种变体、四族居民;主持细则(第一条线索防直白的四不两测、居民复述范本、状态机、义项锁定、私下正反六例、居民原初词账、随身口令、锦囊三级、校准一问、命名六刀、字面冷读、概念工程与反事实回望);二代英文协议与工具箱里的独有内容译并入中文各册。
